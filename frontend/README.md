# Frontend

Next.js (App Router) arayüzü. Projenin tamamı için [kök README](../README.md)'ye bakın.

```bash
npm install
npm run dev          # http://localhost:3000 (backend http://localhost:8080 adresinde bekleniyor)
npm run lint         # mimari kuralları dahil
npm run typecheck
npm run test:e2e     # çalışan yığına karşı Playwright testleri
```

Backend başka bir adresteyse `NEXT_PUBLIC_API_URL` ile verin.
